# 小红书多图封面系统

这是一个 Codex skill，用于基于个人素材库、人设和帖子内容生成小红书风格多图封面，并可把生成后的多图帖子上传发布到万神殿。

## 安装

把 `skills/xiaohongshu-cover-system` 复制到本机 Codex skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R skills/xiaohongshu-cover-system ~/.codex/skills/
```

## 触发方式

可以直接对 Codex 说：

```text
用小红书多图封面系统，基于我的素材库和人设，给这篇帖子生成 6 张封面图并上传到万神殿。
```

最好提供：

- 帖子主题或正文草稿
- 账号人设
- 素材库文件夹路径
- 想生成的图片数量
- 如果要发布到万神殿，提供 API key 的安全来源、标题、正文和标签

## 能力

- 自动判断帖子类型和适合的封面风格
- 生成小红书 carousel 多图封面方案
- 输出每张图的标题、布局、素材使用方式和生成提示词
- 使用本地素材库保持人设和视觉统一
- 将第一张图作为万神殿封面，后续图片作为图集上传发布
