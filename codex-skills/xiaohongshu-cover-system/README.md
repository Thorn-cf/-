# 小红书多图封面系统

这是一个 Codex skill，用于基于个人素材库、人设和帖子内容，稳定生成小红书风格多图封面，并可把生成后的多图帖子上传发布到万神殿。

它的重点不是“随便生成一张好看的封面”，而是形成一套可复用流程：先判断帖子类型和账号人设，再选择合适的小红书封面家族，最后输出完整的 carousel 多图方案或直接发布。

## 安装

把本目录复制到本机 Codex skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R codex-skills/xiaohongshu-cover-system ~/.codex/skills/
```

安装或更新后，可以让 Codex 重启/刷新技能列表，之后用自然语言触发。

## 触发方式

可以直接对 Codex 说：

```text
用小红书多图封面系统，基于我的素材库和人设，给这篇帖子生成 6 张封面图。
```

也可以带上万神殿发布需求：

```text
用小红书多图封面系统，基于 /path/to/assets 里的素材，给这篇 AI 工具教程做 6 张封面图，并上传到万神殿。标题是……正文是……标签用 图像、科普。
```

更短的触发方式也可以：

```text
帮我做一组适合小红书的多图封面
```

```text
生成封面图并发到万神殿
```

## 最佳输入

为了效果稳定，最好提供：

- 帖子主题或正文草稿
- 账号人设，比如 AI 工具博主、职场成长博主、生活方式博主
- 素材库文件夹路径
- 想生成的图片数量，默认 6 张
- 图片比例，默认 `3:4`
- 是否需要真实生成图片，还是只要封面方案和提示词
- 如果要发布到万神殿，提供 API key 的安全来源、帖子标题、正文和标签

没有提供完整信息时，skill 会使用安全默认值：`实用型知识博主`、`6 张图`、`3:4`、第一张做封面、后续图片做图集。

## 能力

- 自动判断帖子类型：教程、清单、观点、测评、案例、个人故事、资源合集、生活记录等
- 自动选择封面风格：大字标题、头像金句、截图标注、专家卡片、杂志拼贴、产品平铺、前后对比、清单卡片等
- 生成小红书 carousel 多图封面方案
- 输出每张图的标题、布局、素材使用方式和生成提示词
- 使用本地头像、截图、产品图、生活图等素材保持人设和视觉统一
- 将第一张图作为万神殿封面，后续图片作为图集上传发布
- 调用万神殿接口发布帖子，并返回帖子 ID / URL

## 兼容弱模型

这个 skill 已经加入低能力模型兼容流程。即使基础模型能力较弱，也会被引导按固定步骤完成任务：

- 至少输出 4 张图，默认 6 张图
- 必须选择一个明确的封面家族
- 必须把第 1 张作为封面，第 2 张以后作为图集页
- 必须给每张图写清楚画面、主标题、副标题、素材和提示词
- 必须区分“封面设计方案”和“万神殿发布动作”
- 信息不足时使用默认人设、默认比例和默认封面类型，不直接停住

低能力模型参考文件在：

```text
references/model-compatibility.md
```

## 万神殿发布

发布流程遵循万神殿接口文档：

1. 本地生成或选定多张图片
2. 第一张图片作为 `coverImageUrl`
3. 其余图片进入 `images[]`
4. 本地图片先通过 `POST /openclaw/file_share` 获取预签名上传地址
5. 再把二进制图片 `PUT` 到 COS
6. 最后调用 `POST /openclaw/post` 创建帖子

可以使用内置脚本：

```bash
PHANTY_API_KEY="你的 key" \
codex-skills/xiaohongshu-cover-system/scripts/phanthy_publish.py \
  --title "帖子标题" \
  --content "帖子正文" \
  --tags "图像,科普" \
  cover-01.png cover-02.png cover-03.png
```

注意：不要把万神殿 API key 写进公开仓库、日志或截图里。

## 推荐工作流

1. 把帖子草稿和素材库路径交给 Codex。
2. 让 skill 判断人设、内容类型和封面家族。
3. 先确认多图 storyboard。
4. 再生成或编辑图片。
5. 需要发布时，提供万神殿 API key 的安全来源。
6. 上传成功后检查帖子 URL。
